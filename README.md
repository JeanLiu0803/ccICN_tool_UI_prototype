# ccICN Tool UI Prototype

Interactive UX prototype for evaluating the future ccICN workflow in Channel Metric Tool. All calculation and S-parameter inputs are mocked.

## Local development

```bash
npm install
npm run dev
```

Build with `npm run build` and preview with `npm run preview`.

## GitHub Pages

The Vite base path matches `/ccICN_tool_UI_prototype/`. The workflow in `.github/workflows/deploy-pages.yml` deploys `dist` when `main` is updated. Set **Pages → Source** to **GitHub Actions** in the repository settings.
